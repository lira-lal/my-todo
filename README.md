# 할 일 정리 (my-todo)

정리 안 된 생각을 일단 던져두고, 필요할 때 할 일로 바꿔서 관리하는 개인용 할 일 관리 웹앱입니다.

🔗 **[https://lira-lal.github.io/my-todo/](https://lira-lal.github.io/my-todo/)**

## 기능

- **할 일 관리**: 추가 / 완료 처리 / 삭제, 날짜 지정 및 변경
- **자동 날짜 그룹핑**: 기한 지남 · 오늘 · 내일 · 이번 주 · 나중에 · 날짜 미정
- **생각 덤프**: 정리 안 된 생각을 일단 기록해두고, 나중에 날짜를 정해 할 일로 전환
- **메모**: 할 일/서브테스크 단위로 메모 작성
- **서브테스크**: 하위 할 일 추가, 서브테스크를 모두 완료하면 메인 할 일 자동 완료
- **기기 간 동기화**: 코드 하나로 폰과 PC에서 같은 목록 확인 (Firebase Firestore 실시간 동기화)
- **모바일 앱처럼 설치**: PWA 지원 — 홈 화면에 추가하면 아이콘으로 실행, 오프라인에서도 열림

## 기술 스택

빌드 도구 없이 순수 HTML / CSS / JavaScript(ES 모듈)로 작성했습니다.

- 데이터 저장: `localStorage` (기기별 로컬 저장) + Firebase Firestore (기기 간 동기화)
- 폰트: [Pretendard](https://github.com/orioncactus/pretendard)
- 배포: GitHub Pages

## 로컬에서 실행하기

별도 빌드 과정이 없어서, 정적 파일 서버로 폴더만 열면 됩니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 프로젝트 구조

```
index.html      마크업
style.css       스타일
app.js          앱 로직 (상태 관리, 렌더링, Firestore 동기화)
sw.js           서비스 워커 (오프라인 캐싱)
manifest.json   PWA 매니페스트
icon-*.png      앱 아이콘
```

## 기기 간 동기화 사용법

1. 우측 상단 "동기화" 버튼 클릭 → 생성된 코드 확인
2. 다른 기기에서 같은 사이트 접속 → "동기화" → 코드 입력 → "연결"
3. 이후 두 기기에서 같은 할 일 목록이 실시간으로 동기화됩니다

코드를 아는 사람은 누구나 해당 목록에 접근할 수 있으니 남에게 공유하지 마세요.
